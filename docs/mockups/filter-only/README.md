# 「照合しないで絞り込みだけ」の 5 案（静的モック）

進め方 §4 に従い、「② と照合せずに、① を絞り込んだ結果だけを表示・出力する」入口と流れを、異なる仮説で 5 案作ったものです。本処理にはつないでいません。
各ファイルを Edge で直接開き、下の帯の「モックの状態」で状態を切り替えて見られます（`?shot=1` で帯と仮説の札を隠す）。

骨組み（上部バー・アイコン列・タブ・表）は `fo-shell.css` / `fo-shell.js`（と上の階層の `mock-common.*`）で 5 案共通にし、違いを「入口と流れ」だけにしています。

| 案 | ファイル | 仮説 |
|---|---|---|
| F1 作業セットの切替 | `plan-f1.html` | 照合するかどうかを作業セットの設定として 1 か所に持てば、どの画面でも今の流れを誤認せず、主要動作も 1 つに保てる |
| F2 主要動作の分岐 | `plan-f2.html` | 設定を増やさず主要動作の ▾ から選ばせれば、普段の流れを変えずに済む |
| F3 照合しない抽出条件 | `plan-f3.html` | 抽出条件の一種にすれば、優先順位・振り分けをそのまま使え、照合と混ぜられる |
| F4 ① タブから出力 | `plan-f4.html` | 見ている表（① の絞り込み後）をそのまま出力できれば、切り替えを考えなくてよい |
| F5 自動で切り替える | `plan-f5.html` | 条件が無ければ自動で絞り込み結果を出せば、判断の数が最少になる |

評価は `../../design/04-絞り込みだけ.md`。

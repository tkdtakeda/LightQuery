# LightQuery（簡易クエリ）

① 元データの各行を ② 条件データの各行（1 行＝1 セットの条件）と照らし合わせ、条件に一致した行を表示・出力するツールです。
Excel の VLOOKUP や Power Query の「結合」に近い動きをします。

「① のどの列を ② のどの列と、どう比べるか」をまとめたものを **抽出条件** と呼び、名前と優先順位を付けて複数（最大 30 件）持てます。
② は抽出条件ごとに持つため、列の構成が違う表（顧客 ID の一覧・地域と金額の表・NG ワードの一覧など）を使い分けられます。

## 使い方

1. このフォルダの `index.html` を Edge で開きます（ダブルクリックで開けます。サーバーは不要です）。
2. 画面右上の青いボタンが、次にすることを示します（① を読み込む → ② を読み込む → 条件を追加する → 抽出する → 出力する）。
3. 詳しい操作は、画面右上の「使い方」から取扱説明書を開いてください。まずは左下の「サンプル」で動きを確かめるのがおすすめです。

- 対応形式：Excel（.xlsx .xlsm .xls .xlsb .ods）、CSV・TSV・TXT（文字コードは自動判定・手動切替）、Excel からの貼り付け（Ctrl+V）
- 出力形式：Excel（.xlsx。まとめ＋抽出条件ごとのシートにも分割可）、CSV（UTF-8 BOM 付き／Shift_JIS／UTF-8 BOM なし）、UTF-16 テキスト、クリップボード
- 抽出条件：名前・優先順位（ドラッグ／順位の数字／Alt+↑↓）・有効／無効・複製・削除（元に戻せる）。複数のファイル・シートから表ごとにまとめて作成
- 条件データの切替：② のタブとパネルで、抽出条件ごとの条件データ（1 位・2 位…）を並べて切り替え・追加できる
- 優先順位：「優先順位で振り分け」（重複なし・初期値）と「それぞれに出力」（重複あり）を切り替え。どれにも該当しない行も「該当なし」として出力可
- Excel の読み込み範囲：ファイルに記録された使用範囲ではなく、実際に値が入っているセルの範囲で読む（記録の外にデータがあれば画面に表示）
- 比較演算子：完全一致・一致しないで、② の値・固定値の先頭の >= ・<= ・> ・< ・<> ・= を比較として読む（>=0.1、<>アヒル、<2011/01/01、= は空欄。Excel の COUNTIF と同じ書き方。照合ルールで切り替え可）
- ワイルドカード：完全一致・一致しないで、② の値・固定値の「*」（全角の「＊」も同じ）を任意の文字として扱う（山田*＝前方一致、*商事＝後方一致、*東京*＝含む、山*郎、*＝空欄以外）。照合ルールで切り替え可
- 見出しの一覧：表の見出しを押すと Excel のオートフィルターと同じ一覧が開く。① / ② は「出力する」スイッチ・値の一覧（件数つき）・条件で絞る・残る行数の見込み・OK、抽出結果は並べ替えと「出力する」
- 絞り込み：① / ② の行を抽出の前に列ごとに減らす（値の一覧から選ぶ／比較方法と値で絞る。すべてを満たす行だけ残す）
- 毎月差し替える表：読み込み範囲（シート・ヘッダー行・開始行・開始列）・絞り込み・列の表示・列の追加を列の名前で記憶し、同じ構成の表を読み込むと自動で当てはめる（終了行は引き継がない）
- 列の追加（読み替え・計算）：① / ② に、対応表（マスタ。直接入力・Excel から貼り付け・ファイル）で読み替える列や、[列名] を使った式（+ − × ÷・括弧・&・ROUND 系）で計算する列を加える。条件・出力・集計で使え、設定は記憶して同じ列のある表に自動で当てはめる
- 日付の条件：以降（から）・以前（まで）・範囲（から〜まで。② の開始日・終了日の列も可、空欄の側は制限なし）・期間（2024／2024/05／2024年度／今日・今月・先月・今年度・直近 N 日 など）
- 照合ルール：空白・全角半角・大文字小文字・数値・日付のそろえ方・ワイルドカード。全体の設定を共通で使い、必要な抽出条件だけ個別の設定にできる
- 表の見た目：列幅は中身の文字数に合わせる（見出しの右端のドラッグで調整）。列の間隔・行の間隔・文字サイズを 3 段階で切替
- ① だけの集計：抽出していないときは、② を使わずに ① 元データの全行（① の絞り込み・列の追加を反映）を集計。抽出後は集計の対象を「抽出結果／① の全行」で切替
- 集計（グループバイ）：「② の行ごと」（② の 1 行＝1 グループ、0 件の行も出す）と「列を選んで集計」の 2 つのしかた。抽出結果を最大 5 列でグループに分け、件数・合計・平均・標準偏差（STDEV.S）・最小・最大と順位（RANK.EQ と同じ）を集計タブに表示。Excel に「集計」シートを付けて出力、集計タブから CSV・コピーも可。集計の行をダブルクリック（Enter）すると、そのグループに入った行（内訳）を集計の表の上に重ねて表示（ピボットの「詳細の表示」と同じ考え方。コピー・Excel 出力つき）
- 列の表示：読み込みパネルの列タグ（列名・列記号で探すと右の表の当てはまる列を強調。条件で使っている列には条件の記号 A・B… を表示）、またはプレビューの見出し（読み込み範囲表示ではヘッダー行の列名）を押して表示／非表示を切替（出力しない列は薄く表示。絞り込み・すべて ON／OFF つき）。抽出条件の列の一覧は表示する列を先に、非表示の列は下にまとめて表示
- 出力列：すべて ON／すべて OFF（絞り込み中は一覧に出ている列だけ）。表示・並び順を列の名前でブラウザに記憶し、次に同じ名前の列を読み込んだときも使う（初期状態に戻せる）
- 進み具合：読み込み・抽出・出力の間は、メイン画面の中央に進み具合のカードを表示（全体の % と段階ごとに区切ったバー・今の段階・経過時間・複数ファイルの何件目か）。5 秒以上進まないと「進みがありません」と知らせ、途中の割合を測れない段階（Excel のブックの解析）は動く縞で示す
- 列を探して選ぶ：列を選ぶ欄（読み替えの元の列・抽出条件の ① / ② の列・絞り込みの列・集計の列）は、入力すると当てはまる列を候補に表示（完全一致 → 列記号 → 前方一致 → 一部一致 → 文字を順に含む。全角半角・大文字小文字・カタカナひらがなは区別しない。↑↓・Enter で選ぶ）
- 作業セット：作業ごとの設定一式（抽出条件と ② のデータ・振り分け・照合ルール・出力列・列の追加・集計・① の読み込み範囲）に名前を付けてブラウザ（IndexedDB）に保存し、上部バー左のセット名から切り替え（最大 50 件・開いているセットに自動保存・新規・複製・名前の変更・削除（元に戻せる）・.json に書き出し／新しいセットとして読み込み）。読み込み済みの ① は切り替えてもそのまま
- 保存：抽出条件（② のデータ・個別の照合ルールを含む）と出力列の並びはブラウザに自動保存して次回復元。JSON に 1 件・一括で書き出し／読み込み（追加・置き換え）して再利用
- インターネット接続：アイコン（Font Awesome）と Excel の読み書き（SheetJS）を CDN から読み込みます。接続できない場合も CSV は使えます。

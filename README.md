# LightQuery（簡易クエリ）

① 元データの各行を ② 条件データの各行（1 行＝1 セットの条件）と照らし合わせ、条件に一致した行を表示・出力するツールです。
Excel の VLOOKUP や Power Query の「結合」に近い動きをします。

「① のどの列を ② のどの列と、どう比べるか」をまとめたものを **抽出条件** と呼び、名前と優先順位を付けて複数（最大 30 件）持てます。
② は抽出条件ごとに持つため、列の構成が違う表（顧客 ID の一覧・地域と金額の表・NG ワードの一覧など）を使い分けられます。

## 使い方

1. このフォルダの `index.html` を Edge で開きます（ダブルクリックで開けます。サーバーは不要です）。
2. 画面右上の青いボタンが、次にすることを示します（① を読み込む → ② を読み込む → 条件を追加する → 抽出する → 出力する）。
3. 詳しい操作は、画面右上の「使い方」から取扱説明書を開いてください。まずは左下の「サンプル」で動きを確かめるのがおすすめです。

- 対応形式：Excel（.xlsx .xlsm .xls .xlsb .ods）、CSV・TSV・TXT（文字コードは自動判定・手動切替）、Excel からの貼り付け（Ctrl+V）
- 出力形式：Excel（.xlsx。まとめ＋抽出条件ごとのシートにも分割可）、CSV（UTF-8 BOM 付き／Shift_JIS／UTF-8 BOM なし）、UTF-16 テキスト、クリップボード
- 抽出条件：名前・優先順位（ドラッグ／順位の数字／Alt+↑↓）・有効／無効・複製・削除（元に戻せる）。複数のファイル・シートから表ごとにまとめて作成
- 条件データの切替：② のタブとパネルで、抽出条件ごとの条件データ（1 位・2 位…）を並べて切り替え・追加できる
- 優先順位：「優先順位で振り分け」（重複なし・初期値）と「それぞれに出力」（重複あり）を切り替え。どれにも該当しない行も「該当なし」として出力可
- Excel の読み込み範囲：ファイルに記録された使用範囲ではなく、実際に値が入っているセルの範囲で読む（記録の外にデータがあれば画面に表示）
- ワイルドカード：完全一致・一致しないで、② の値・固定値の「*」（全角の「＊」も同じ）を任意の文字として扱う（山田*＝前方一致、*商事＝後方一致、*東京*＝含む、山*郎、*＝空欄以外）。照合ルールで切り替え可
- 日付の条件：以降（から）・以前（まで）・範囲（から〜まで。② の開始日・終了日の列も可、空欄の側は制限なし）・期間（2024／2024/05／2024年度／今日・今月・先月・今年度・直近 N 日 など）
- 照合ルール：空白・全角半角・大文字小文字・数値・日付のそろえ方・ワイルドカード。全体の設定を共通で使い、必要な抽出条件だけ個別の設定にできる
- 表の見た目：列幅は中身の文字数に合わせる（見出しの右端のドラッグで調整）。列の間隔・行の間隔・文字サイズを 3 段階で切替
- 集計（グループバイ）：抽出結果を最大 5 列でグループに分け、件数・合計・平均・標準偏差（STDEV.S）・最小・最大と順位（RANK.EQ と同じ）を集計タブに表示。Excel に「集計」シートを付けて出力、集計タブから CSV・コピーも可
- 出力列：すべて ON／すべて OFF（絞り込み中は一覧に出ている列だけ）。表示・並び順を列の名前でブラウザに記憶し、次に同じ名前の列を読み込んだときも使う（初期状態に戻せる）
- 保存：抽出条件（② のデータ・個別の照合ルールを含む）と出力列の並びはブラウザに自動保存して次回復元。JSON に 1 件・一括で書き出し／読み込み（追加・置き換え）して再利用
- インターネット接続：アイコン（Font Awesome）と Excel の読み書き（SheetJS）を CDN から読み込みます。接続できない場合も CSV は使えます。

## ファイル構成

html・js・css はすべて同じフォルダに置きます。

| 種類 | ファイル | 役割 |
|---|---|---|
| 画面 | `index.html` | 画面の骨組みと読み込み順 |
| 見た目 | `lq-tokens.css` | デザイントークン（色・余白・文字・高さ・動き）。生の値はここだけに書く |
| | `lq-base.css` | リセット・画面の骨組み・上部バーのチップ・左のアイコン列 |
| | `lq-controls.css` | ボタン・入力・切替・バッジ・状態表示 |
| | `lq-overlays.css` | 進捗・反映の合図・通知・小窓・モーダル・ドロップ領域 |
| | `lq-grid.css` | タブ・要約・表・ページ送り・空の状態 |
| | `lq-panels.css` | 各設定パネル・出力・サンプル・取扱説明書の中身 |
| | `lq-profiles.css` | 抽出条件の一覧・編集欄・② のカード・結果の絞り込み・表の選択などの小窓・照合ルールの対象 |
| | `lq-aggregate.css` | 集計パネル（グループにする列・集計する値・順位） |
| | `lq-condtables.css` | 条件データの切替（② タブの切替ボタン・② パネルの一覧） |
| 処理 | `lq-core.js` | 名前空間・イベント・DOM 生成・書式・設定の記憶・分割実行 |
| | `lq-text.js` | 数値・日付の解釈、照合ルールによる正規化、ワイルドカード（*）の当てはめ |
| | `lq-period.js` | 期間の解釈（年・年月・年度・日付と、今日・今月・直近 N 日などの今日を基準にした言葉） |
| | `lq-readers.js` | 文字コード判定・CSV 解析・Excel 読み込み・貼り付け・保存データ・シートの複製 |
| | `lq-dataset.js` | ヘッダー行・開始行・開始列・終了行の適用と自動判定 |
| | `lq-operators.js` | 比較方法の登録簿（追加は `register()` だけ。範囲・期間・日付向けの呼び方を含む） |
| | `lq-logic.js` | 組み合わせ式の解析・検証・読み下し |
| | `lq-engine.js` | 抽出エンジン（1 抽出条件分：1 行＝1 セット、空欄は判定しない、結合の種類、索引、進捗・中止） |
| | `lq-profiles.js` | 抽出条件のモデル（条件の操作・抽出条件・優先順位の一覧） |
| | `lq-batch.js` | 複数の抽出条件の一括実行と、優先順位での振り分け／それぞれに出力・該当なし |
| | `lq-resultview.js` | 出力列の解決・抽出条件ごとの絞り込み・並べ替え・出力用の行 |
| | `lq-output-columns.js` | 出力列の並びと表示の記憶（今は使っていない列も名前で覚え、読み込んだときに元の位置へ戻す） |
| | `lq-state.js` | 状態管理（変更通知・抽出条件の一覧・照合ルール（全体／個別）・サンプルの退避・取り消し用スナップショット） |
| | `lq-exporters.js` | 出力（Excel の複数シート・Shift_JIS 変換表を含む） |
| | `lq-bundle.js` | 抽出条件の JSON（1 件・一括・旧形式）の書き出しと読み込み |
| | `lq-storage.js` | 抽出条件と出力列の並びのブラウザへの自動保存と復元（② の容量上限つき） |
| | `lq-aggregate.js` | 集計の設定（AggregateSettings）と計算（Aggregator：グループ分け・件数・合計・平均・標準偏差・最小・最大・順位） |
| | `lq-samples.js` | サンプルデータ（13 パターン） |
| 画面部品 | `lq-ui-kit.js` | 入力補助・反映の合図・通知・小窓・開閉できる区画・部品の組み立て |
| | `lq-ui-shell.js` | 上部バー・左のアイコン列・パネルの入れ物・ドラッグ＆ドロップ・貼り付け・キー操作 |
| | `lq-ui-main.js` / `lq-ui-grid.js` | メイン領域（タブ・要約・抽出条件ごとの絞り込み・ページ送り）／表の描画（列幅は中身に合わせる） |
| | `lq-ui-grid-sizing.js` | 表の見た目（列の間隔・行の間隔・文字サイズの 3 段階）と列幅の手動調整 |
| | `lq-ui-cond-tables.js` | 条件データの切替（② タブの切替ボタン・② パネルの一覧・条件データの追加） |
| | `lq-ui-dataset-panel.js` | ① / ② の読み込みパネル（② は選択中の抽出条件のもの。上部に条件データの一覧） |
| | `lq-ui-profile-list.js` | 抽出条件の一覧（優先順位・有効／無効・並べ替え・振り分けの設定） |
| | `lq-ui-cond-row.js` | 条件 1 行の編集欄（範囲の開始〜終了・日付の列の判定と日付向けの呼び方・期間の候補） |
| | `lq-ui-query-panel.js` | 抽出条件パネル（一覧＋選択中の抽出条件の編集：名前・②・照合ルール・組み合わせ・条件・抽出のしかた） |
| | `lq-ui-output-panel.js` | 出力列パネル（表示・並べ替え・初期状態に戻す） |
| | `lq-ui-aggregate-panel.js` / `lq-ui-aggregate-view.js` | 集計パネル（設定）／集計タブ（表・要約・除いた件数の案内） |
| | `lq-ui-rules-panel.js` | 照合ルールパネル（全体の設定／この抽出条件だけの設定） |
| | `lq-ui-dialogs.js` | メニュー・サンプル・読み込み先・読み込み範囲の小窓 |
| | `lq-ui-result-dialogs.js` | 出力・行の根拠・結果の根拠の小窓 |
| | `lq-ui-profile-dialogs.js` | 抽出条件の操作メニュー・JSON の書き出し・一括読み込みの方法・表の選択・すべてクリアの確認 |
| | `lq-manual.js` | 取扱説明書 |
| 操作 | `lq-app-profiles.js` | 抽出条件の操作（追加・複製・削除・優先順位・照合ルールの対象・表から作成・JSON・サンプル） |
| | `lq-app-export.js` | 出力の操作（表示中の表・まとめ＋シート分け・根拠の記録） |
| | `lq-app.js` | 組み立てと操作（主要動作の決定・読み込み・抽出・取り消し） |

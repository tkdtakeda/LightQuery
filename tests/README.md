# 動作確認（tests）

LightQuery の主な機能を、ブラウザで `index.html` を開いて実際に動かして確かめるスクリプトです。ツールを使うだけなら、このフォルダは要りません（ツール本体は 1 つ上のフォルダの html・js・css だけで動きます）。

機能を足したり直したりしたあとに実行すると、これまでの機能が壊れていないかを数十秒で確かめられます。

## 準備（初回だけ）

1. [Node.js](https://nodejs.org/)（18 以上）を入れます。
2. このフォルダでコマンドを実行します。

```
cd tests
npm install
npx playwright install chromium
```

Edge で確かめるときは、最後の行の代わりに、実行時に `LQ_BROWSER=msedge` を付けます（下記）。

## 実行

```
npm test
```

結果は確認ごとに `✔`（通った）／`✘`（失敗。理由つき）で表示し、最後に「12 / 12 件が通りました」のようにまとめます。1 件でも失敗すると終了コードが 1 になります。

| したいこと | コマンド |
|---|---|
| 一部の確認だけ動かす（名前に含む言葉で選ぶ） | `node run-tests.js 関数 年度` |
| Edge で確かめる（Windows） | `set LQ_BROWSER=msedge` のあと `npm test` |
| ブラウザの場所を指定する | `LQ_BROWSER_PATH=/path/to/chrome npm test` |

## 確かめていること

処理の順（読み込み → 前処理 → 抽出 → 結果 → 保存）に並べています。

| 確認 | 中身 |
|---|---|
| 取扱説明書 | 「3 分で使う」から開く・目次の検索・前へ／次へ・「サンプルで試す」 |
| サンプル | 全パターンを読み込んで抽出できる・サンプルデータのみクリア |
| 縦に結合・重複の削除 | 列を名前でそろえる・見出しの位置の自動判定・元ファイル列・処理の流れの行数 |
| ファイルを足す・外す | まとめて読み込む・下に足す・外す |
| 縦持ち | 列のおすすめ・列の名前・空欄を除く・絞り込み・次回の掛け直し |
| 計算の関数 | 82 通りの式の計算結果・誤った式を知らせる |
| 照合ルール・正規表現 | 表記ゆれ（かな・法人格・記号）・正規表現（抽出・絞り込み・書き方の誤り） |
| 一致しなかった ② の行 | 受注のない顧客だけが残る |
| ピボット・年度 | 重複を除いた件数（総計も重複を除く）・年度の始まりによる月の並び・期間 |
| 前回との違い | 直前の抽出結果との比較・開き直しても残る・表で見る |
| 記憶 | 重複の削除の掛け直し・作業セットへの保存 |
| 速さ | 10 万行 × ② 1,000 行の抽出が 3 秒以内 |

## 確かめていないこと

インターネット上のライブラリを使う部分（アイコンの表示・Excel ファイルの読み書き・グラフの描画）は、接続できない環境でも通るように対象にしていません。これらは画面を開いて目で確かめてください。
